# weighted-accuracy

This repo contains code used to showcase the weighted-accuracy metric presented in the paper [Cost-Sensitive Evaluation for Binary Classifiers](https://arxiv.org/abs/2510.22016) with the aid of two use cases.

The use cases and results are contained in the `WA_corr_matrices.ipynb` notebook.

By default it relies on our cached results, since the computation can be quite long. 
If you want to test it for yourself, simply uncomment the lines of code featureing the `corr_matrices_calculator` method.
